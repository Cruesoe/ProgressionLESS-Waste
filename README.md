# ProgressionLESS: Waste

**All the Progression goodness, less research.**

Colonists pack the filth they clean into trash, which looks different in each era, with trash bins, dumpsters and a garbage truck to manage it.

The "LESS" is less research: Progression: Waste adds up to N research projects depending on your mods. This fork groups them into at most M, such as A, B and C. Everything stays in the same era, and still needs the other research it did before.

Forked from [Progression: Waste](https://steamcommunity.com/sharedfiles/filedetails/?id=3841676471) by ferny. Huge thanks to ferny for the original mod and all the Progression work this builds on.
