# ProgressionLESS: Waste

**All the Progression goodness, less research.**

Colonists pack the filth they clean into trash, which looks different in each era, with trash bins, dumpsters and a garbage truck to manage it.

The "LESS" is less research: Progression: Waste adds just one research project, Dumpsters, and this fork keeps it. It completes the ProgressionLESS set, so any later research changes have a home.

Forked from [Progression: Waste](https://steamcommunity.com/sharedfiles/filedetails/?id=3841676471) by ferny. Huge thanks to ferny for the original mod and all the Progression work this builds on. For a really good modpack, check out [The Progression Modpack](https://steamcommunity.com/sharedfiles/filedetails/?id=3521297585).
